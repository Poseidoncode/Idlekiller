# Security Policy

## Supported Versions

Security updates are applied to the latest commit on the `main` branch. Older
releases are not actively backported.

## Reporting a Vulnerability

If you discover a security issue, please report it privately via the
[GitHub Security Advisories](https://github.com/Poseidoncode/Idlekiller/security/advisories)
page or by opening a GitHub issue with sensitive details redacted.

We will acknowledge the report and aim to respond as soon as possible.

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities before a fix has been
released and users have had reasonable time to update.
